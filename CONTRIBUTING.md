# Contributing

ZeroCool jobs start with a GitHub issue. To test the sandbox, pick an existing issue or file one with a clear description and steps to reproduce the problem, if available. ZeroCool reads and triages the issue. If the job produces a fix, the bot opens a pull request for review.

Review the bot’s pull request as you would any other. You can merge it or close it: the sandbox tests the workflow, not the outcome of any one pull request. The planted bugs are test fixtures, so leave them alone while a job is running.
